This is my first book club post! I'm going to start with some prerequisites to remind myself how this type of math works. 

Functional analysis is a field I've always wanted to study. I started taking Math 202B my last semester at Berkeley (the grad functional analysis course), but unfortunately had to drop because I was taking too many classes. I've always wanted to revisit it, so now am using this reading group as an excuse to finally learn some stuff about the topic.
